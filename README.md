# E-Commerce Sales Analysis Using Excel

## Project Overview
This project analyzes e-commerce sales data using Microsoft Excel to understand sales performance, profitability, product performance, and regional performance.

## Objectives
- Analyze total sales and profit.
- Compare product and category performance.
- Evaluate regional sales and profitability.
- Build an interactive dashboard using PivotTables, charts, and slicers.
- Develop data-driven business insights and recommendations.

## Tools Used
- Microsoft Excel
- Excel Tables and formulas
- XLOOKUP
- IF
- PivotTables
- Charts
- Slicers

## Key Performance Indicators
- Total Sales: ₹29,920
- Total Profit: ₹7,680
- Total Orders: 14
- Overall Profit Margin: 25.67%

## Key Findings
1. T-Shirts generated the highest product profit at ₹1,430.
2. Grocery generated the highest category sales at ₹11,270.
3. Electronics generated the highest category profit at ₹3,120.
4. East generated the highest regional profit at ₹2,060.
5. West achieved the highest regional profit margin at approximately 28.16%.

## Business Recommendations
- Investigate T-Shirt promotional opportunities while considering demand, inventory, and promotion costs.
- Review Grocery costs and discounts to identify opportunities to improve profitability.
- Evaluate regional performance using sales, profit margins, customer demand, and marketing costs before allocating additional investment.

## Project Limitations
- The dataset contains only 14 orders from January 2026.
- The findings are preliminary and may not represent long-term business performance.
- Advertising costs and customer acquisition data were not available.
